# network-lab
- 네트워크 기초를 직접 실습하며 익히기 위한 학습용 레포지토리입니다.  
- TCP/IP, HTTP/HTTPS, DNS, 서브네팅, 라우팅 같은 주제를 Jupyter Notebook으로 정리했습니다.  
- 각 노트북은 단계별 실습과 간단한 확인 테스트(ping 등)를 포함합니다.  

# Roadmap
- 1단계: 컴퓨터 과학(CS) 기초
  - 운영체제: 운영체제 기본 개념과 리눅스(Linux) 명령어, 프로세스 및 메모리 관리 학습
  - **네트워크: TCP/IP, HTTP/HTTPS, DNS, 방화벽, 서브넷팅 등 네트워크 기초 습득**
- 2단계: 클라우드 개념 및 플랫폼
  - 기본 모델: IaaS, PaaS, SaaS의 차이점과 클라우드 컴퓨팅 원리 이해
  - 주력 플랫폼: 시장 점유율이 가장 높은 AWS 선택 (필요시 Azure 또는 GCP 병행)
  - 핵심 서비스: EC2(가상 서버), S3(스토리지), IAM(권한 관리), VPC(네트워크 가상화), RDS(데이터베이스) 실습
- 3단계: 인프라 자동화 및 컨테이너
  - 가상화 도구: 도커(Docker)를 이용한 컨테이너 기술 학습
  - 오케스트레이션: 쿠버네티스(Kubernetes) 기본 구조와 운영 익히기
  - IaC(코드 기반 인프라): 테라폼(Terraform)을 활용해 인프라를 코드로 구축
- 4단계: 운영, 모니터링 및 자격증
  - 모니터링: AWS CloudWatch 등을 통한 로그 분석 및 장애 대응 연습
  - 자격증 취득: AWS Certified Solutions Architect (SAA) 등 실무 연계 자격증 도전
